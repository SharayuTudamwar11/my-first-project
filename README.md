# BMI Calculator

A simple Python project that calculates Body Mass Index (BMI).

## Features

- Takes weight as input
- Takes height as input
- Calculates BMI
- Displays a BMI category

## Requirements

Python 3

## How to Run

Run the following command:

python main.py

## Learning Outcome

This project helps beginners understand Python input,
calculations, variables, and if-else conditions.
